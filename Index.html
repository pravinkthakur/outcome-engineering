How scoring works
We map each score to a non-linear index (1→0, 2→25, 3→50, 4→80, 5→100), average by pillar (weights applied), then:
  • Gates: Must pass all to exceed Level 3.
  • Caps: Lead time/Release < 3 → cap 2.4, Proximity ≤2 → cap 2.9, Traceability ≤2 → cap 3.0.
